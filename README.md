# frank-sq — 开源项目与插件仓库

> Frank 的开源共享仓：把自己开发的项目、插件通过开源方式共享给大家。
> 每个可开源项目 / 插件以独立子项目文件夹托管在 `projects/` 下，一项目一文件夹。

## 如何浏览

- 进入 `projects/<子项目>/` 查看各项目说明（`README.md`）与发布/跟进日志（`PROJECT-LOG.md`）。
- 每个子项目独立维护自己的版本、待办与发布记录。

## 协议

本仓库及各子项目默认采用 **MIT** 协议，详见 [LICENSE](./LICENSE)；个别子项目可在其目录内单独声明协议。

## 反馈

- 问题与建议：在本仓库提 Issue。
- 想贡献：Fork 后提 PR，合入前需通过脱敏检查（见 [CLAUDE.md](./CLAUDE.md)）。
